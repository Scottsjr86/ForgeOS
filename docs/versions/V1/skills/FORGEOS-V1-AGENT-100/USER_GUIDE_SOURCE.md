# FORGEOS-V1-AGENT-100 User Guide Source

Status: `CLOSED`
Validation: `OPERATOR_ACCEPTED`

ForgeOS can submit an exact remote-agent request to Nyx and display the returned
Nyx-owned task record, including provider, model, source revision, worktree, scope,
budget, state, output or failure, execution counts, recorded cost, and immutable
identities.

ForgeOS can cancel or continue only the exact queued record it received. Terminal
records cannot be presented as resumable. Nyx_Server remains independently usable
for chat, development, tools, and other API clients.
